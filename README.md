# 📖 Overview

AI Learning Assistant is an educational chatbot built using **Retrieval-Augmented Generation (RAG)** that answers questions related to Artificial Intelligence.

Instead of generating random answers, the assistant performs **semantic search** over educational video transcripts, retrieves the most relevant knowledge chunks, and generates accurate responses using an LLM.

# 💡 How it Works

1. User asks a question.

2. The query is converted into an embedding.

3. Semantic Search finds the most relevant transcript chunks.

4. Retrieved knowledge is added to the prompt.

5. Llama 3.2 generates a context-aware response.

6. Response is displayed in the React interface.
